## Opening the 3D model locally

Double-click `living-room-3d/index.html`. It loads three.js from a CDN, so it needs an internet connection.

Controls on the right side: counter-table choice, position, rotation, stools in use or pushed in,
ottoman / coffee table swap, and layer toggles. Click any item for its dimensions.
